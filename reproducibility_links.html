Code and Data for Reproducibility

Development and Evaluation of a Physics-Informed Hybrid SARIMAX-LSTM Model Using Clear-Sky Index-Informed Learning for Year-Ahead Global Horizontal Irradiance Forecasting and Spatial Mapping in the Philippines

Each link opens a file on GitHub, where it can be viewed or downloaded. Notebooks (.ipynb) show the code with its outputs, and small CSV files show as a table. README.md gives the order in which to run the notebooks.

Overview

  • Whole repository – every file of the study
  • Download everything (ZIP) – the whole repository as one file
  • README.md – How to run the study: notebook order, data sources and reproducibility notes
  • requirements.txt – Python libraries and the exact versions used
  • Reproducibility_Links.ipynb – Creates this list of links

Data acquisition

Code

  • Philippine Map Create_Grid.ipynb – Creates the 1° × 1° grid, keeps the 93 cells that intersect Philippine land and assigns each a representative query point
  • Data_Extraction_NASAPOWER.ipynb – Downloads monthly GHI, cloud amount and relative humidity (2005–2024) from NASA POWER for the 93 grids
  • Elevation_Extraction.ipynb – Extracts SRTM elevation at each grid's query point through OpenTopoData

data/processed/

  • grid_metadata.csv – The 93 grid cells: bounds, centre, query point, area and land coverage
  • philippines_grid.geojson – The 93 grid cells as polygons, for GIS software

data/raw/nasa_power/

  • nasa_power_monthly.csv – NASA POWER monthly GHI, cloud amount and relative humidity per grid, 2005–2024, as downloaded

data/raw/elevation/

  • grid_elevation.csv – Elevation (m) of each grid's query point and its source dataset

Data pre-processing

Code

  • Data_Preprocessing_Validation.ipynb – Checks structure, missing values, physical validity, outliers and other quality issues; adds extraterrestrial irradiance (H0) and the clearness index (Kt)

data/processed/

  • nasa_power_validated.csv – Validated dataset, 2005–2024, with H0, Kt and quality flags (input of the models)

data/processed/quality/

  • validation_summary.csv – Result of each of the 25 data-quality checks
  • flagged_records.csv – Values flagged as outliers (|modified z| > 3.5), with details

Comparative and ablation analysis

Code

  • Comparative_Ablation_Analysis.ipynb – Diebold-Mariano tests with HLN correction for the comparative and ablation analyses (2015–2024), and RMSE difference maps

outputs/significance_tests/

  • model_accuracy_full_record.csv – RMSE, MAE and nRMSE of every model over the full record, 2015–2024
  • comparative_dm_hln.csv – Comparative analysis: proposed model vs. SARIMAX, LSTM, XGBoost, climatology and seasonal naive (DM-HLN, Holm-adjusted)
  • ablation_dm_hln.csv – Ablation analysis: the three hybrid variants compared (DM-HLN, Holm-adjusted)
  • per_grid_dm_hln.csv – DM-HLN test per grid for each comparison (Benjamini-Hochberg FDR-adjusted)
  • loss_differentials_monthly.csv – Monthly loss differentials used in the tests, 2015–2024

Final model training and 2026 forecast

Code

  • Final_Product_2026.ipynb – Checks the proposed model on 2025, retrains it on 2005–2025 and forecasts 2026, with maps

data/raw/nasa_power/

  • nasa_power_monthly_2005_2025.csv – NASA POWER monthly GHI, cloud amount and relative humidity per grid, 2005–2025, as downloaded for the final model

data/processed/

  • nasa_power_validated_2005_2025.csv – Validated dataset, 2005–2025, with H0, Kt, elevation and month terms (input of the final model)

outputs/final_product_2026/

  • forecast_2026_monthly.csv – 2026 forecast: monthly GHI per grid, with clear-sky GHI, CSI and the two component forecasts
  • forecast_2026_annual.csv – 2026 forecast: annual mean daily GHI and annual total GHI per grid, compared with the 2005–2025 average
  • check_2025_predictions.csv – 2025 check: forecast vs. observed GHI per grid and month
  • check_2025_metrics.csv – 2025 check: RMSE, MAE, nRMSE, R² and skill of the proposed model, its two components and climatology
  • nasa_power_request_header.json – NASA POWER API version, sources and period of the 2005–2025 download
  • nasa_power_revisions_vs_development.csv – Comparison of the 2005–2024 values of the two NASA POWER downloads (no value was revised)
  • environment.txt – Python and library versions used for this run

outputs/final_product_2026/models/

  • sarimax_csi_diagnostics.csv – SARIMAX (CSI) order, AIC, convergence and Ljung-Box p-value per grid, 2025 and 2026
  • tvwa_weights.csv – TVWA weights per grid, 2025 and 2026
